##Результаты замера Debug vs Release
| Режим | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум |
|-------|---------:|---------:|---------:|---------:|---------:|--------:|
| Debug | 718 с | 685 с | 733 с | 699 с | 744 с | 685 с |
|Release | 347 мс | 339 мс | 346 мс | 346 мс | 338 мс | 338 мс |
В моём эксперименте Release оказался быстрее/медленнее Debug примерно в 2 раза.
При сравнении IL я обнаружила: 1. Для функции add в режиме debug присутствует метод nop, инициализация переменных и инструкции ссылки, в режиме release остальсь лишь несколько инструкций из всех тех, что есть в режиме debug. 2. Для функции sumto в режиме debug также присутствует всё то, что я перечла ранее, но иструкций стало намного больше, чем было в add, в режиме release остались инициализации переменных, но их стало меньше по сравнению с режимом debug, остальная структура совпадает со структурой функции add в этом же режиме (но инструкций стало чуть побольше). 3. Сравнивая режимы Debug и Release, могу сказать, что Release значительно упрощает выполнение (много чего игнорирует, но только то, что не влияет на корректное выполнение программы), поэтому и работа в этом режиме занимает меньше времени.
